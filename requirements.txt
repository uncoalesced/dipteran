# Dipteran direct dependencies, pinned to the versions Phase 1 was verified

# torch MUST come from the CUDA 12.8 index. The RTX 5050 this was built on is
# Blackwell (compute capability sm_120) and pre-cu128 wheels ship no kernels
# for it -- they import cleanly and then fail at the first kernel launch.
#
#   uv venv --python 3.12 .venv
#   uv pip install -r requirements.txt
#   uv pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu128
#
# Not installable from here: SUMO. Install it from your package manager
# (`apt-get install sumo sumo-tools sumo-doc`) so `netconvert` and
# `duarouter` are on PATH, or set sumo.binary_dir in config.yaml.
